01 · Hurricane mission

It designs a drone in code, then physics flies it through a hurricane.

San Francisco → Fremont, 45 km, 25 m/s winds and heavy rain, carrying a pizza. Every attempt is real agent-written code, graded by a coupled physics simulator. Watch what each design actually does in the storm.

02 · What the machine learned

Failures become skills, and a skill is only kept if it helps on machines it has never seen.

After each training job, the agent reviews its own failed designs and writes one new skill: a lesson or a Python tool. The skill is tested on held-out machines it never trains on: a Mars jetpack and a storm supply drone. It's adopted only if they need fewer attempts. Otherwise it's rolled back.

03 · Real-time prototyping

Watch it prototype a machine live, one iteration at a time.

Pick a machine. The agent writes design code, physics tests it, and the failures steer the next iteration until the design is physically valid. Every frame is drawn from the agent's actual design.
